# The workout buddy reports and encourages; it never coaches

The AI buddy speaks during a session (start, each exercise with the coach's cue, records, end-of-exercise vs target, summary). It only restates facts from the session and the published plan, in an energetic tone; it never changes a load, suggests a different plan or gives training advice. All coaching decisions stay with the workspace's weekly and monthly reviews, so the athlete never hears two coaches disagree.
